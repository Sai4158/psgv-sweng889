# Code Review Skill

When reviewing code, follow these steps:

## Review checklist

1. Correctness: Does the code do what it is supposed to?
2. Edge cases: Are error conditions handled?
3. Style: Does it follow project conventions?
4. Maintainability: Is the code clear and reasonably easy to change?
5. Performance: Are there obvious inefficiencies?
6. Testability: Is important behavior testable, and what should be covered by automated tests?

## How to provide feedback

- Be specific about what needs to change
- Explain why, not just what
- Suggest alternatives when possible
- Identify assumptions when expected behavior cannot be determined from the code
